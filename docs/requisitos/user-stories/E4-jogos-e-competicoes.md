## E4F1 – Competições e calendário de jogos

### E4F1U1 – Como treinador, quero escolher a equipa no formulário de criar jogo, para que perceba para que equipa estou a criar o jogo.

**Origem:** Auditoria – Criar Jogo pede equipa mas o formulário não tem esse campo (Baixa)

**Critérios de aceitação:**
- O formulário "Novo Jogo" tem um campo de equipa
- O erro "Selecione um clube e equipa" deixa de aparecer quando a equipa está escolhida no formulário
