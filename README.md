## Sobre o projeto

O ClubOps360 é uma plataforma web (SaaS) de gestão de clubes desportivos, multi-modalidade e multi-época, com perfis para dirigentes, treinadores, staff, atletas e encarregados de educação. A plataforma encontra-se em fase de protótipo.

O objetivo deste TFC é **estabilizar e fazer crescer a plataforma**, para que cubra as necessidades de um clube de pequena e média dimensão, e não apenas a gestão de treinos.
